# 决策记录

> 只记「定了什么、为什么、什么时候能翻案」。流水看 `PROGRESS.md`，现状看 `PROJECT_STATE.md`。
> 新增格式：`YYYY-MM-DD · 标题` + 三行（决定 / 理由 / 翻案条件）。

## 2026-11-14 · 撤回 1.0.25–1.0.28，回到 1.0.24 基底
- **决定**：保险箱、红后灯带、隐藏思考、分层宠物全部撤出，只保留选字滚动修复，版本记 1.0.28。
- **理由**：全版功能一次没构建过；保险箱是唯一新增 Kotlin，构建风险最高；用户要的是能用的包，不是功能多的包。
- **翻案**：完整实现在分支 `archive/1.0.28-full`，想捡回来从那里取。

## 2026-11-14 · 密钥保险箱不做
- **决定**：从待办剔除，不再排期。
- **理由**：使用频率低；Kotlin 五个坑（`appContext`、`status` 返回类型、`SecretKeyFactory`、插件按 Activity 注册、`INSTALL_DONE` 释放锁）已记录，重做成本高于收益。
- **翻案**：用户重新提出即可，代码在存档分支。

## 2026-11-14 · 1.0.29 定为回退基线
- **决定**：出问题回退到 1.0.29 / `11140932`。
- **理由**：第一个选字滚动真机验证通过的版本。
- **翻案**：出现更稳的版本时改标。

## 2026-11-14 · 记忆用文件，不装第三方记忆插件
- **决定**：保留 `mem.sh` 文件式记忆；插件市场里的 `dsh-plugin-memory` 只借思路（门类加权、信任层级、取代标记），不迁移。
- **理由**：记忆量几百条，文件够用且可读；插件面板在 dsh-go 原生界面看不到；迁移要重写人设与库结构。
- **翻案**：条目过千，或一周内出现两次「记过却查不到」。

## 2026-11-14 · 可选插件只开压缩相关
- **决定**：开 `compaction-basic`、`command-compact`、`tool-result-pruner`；`plugin-market`、`plan-mode`、`voice-input` 不开。
- **理由**：长会话与长输出是实际痛点，其余是"看着有用"。
